# 张一鸣通识课

> 张一鸣的思想书架 · 100 本经典 · 构建创业者的操作系统

## 📖 课程简介

基于字节跳动创始人 **张一鸣** 的阅读轨迹与思想体系构建的 100 门通识课。每课精读一本他反复研读或公开推荐的经典，还原「书 → 制度」的翻译逻辑——张一鸣如何把书中的抽象思想，翻译成字节跳动的产品、管理和文化。

## 🗂️ 课程范围

覆盖产品观、管理观、思维观、学习观、格局观五大模块，包括：

- **产品与创业**：乔布斯传、从 0 到 1、精益创业、闪电式扩张、创新者的窘境
- **管理与组织**：奈飞文化、重新定义公司、七个习惯、德鲁克、赢
- **思维与格局**：原则、思考快与慢、禅者的初心、当下的力量、三体、人类简史
- **学习方法**：如何阅读一本书、深度工作、掌控习惯
